# PyTraffic Interceptor

Расширение для Chrome (Manifest V3), которое перехватывает WebSocket-трафик и показывает его в отдельной панели DevTools. Удобно для отладки realtime-приложений (чаты, торги, игры).

## Возможности

- Перехват **WebSocket**-сообщений (отправленных и полученных) через инъекцию сниффера в страницу
- Просмотр трафика в панели **DevTools** (вкладка PyTraffic)
- Отображение направления, времени, размера и содержимого сообщений
- Работает на всех сайтах (`<all_urls>`)

## Установка

1. Скачайте или склонируйте репозиторий
2. Откройте `chrome://extensions`
3. Включите «Режим разработчика»
4. Нажмите «Загрузить распакованное расширение» и выберите папку проекта

## Использование

1. Откройте DevTools (F12) на интересующем сайте
2. Перейдите на вкладку **PyTraffic**
3. Взаимодействуйте со сайтом — сообщения WebSocket будут появляться в панели

## Структура

- `devtools.html` / `devtools.js` — регистрация панели DevTools
- `panel.html` / `panel.js` — UI панели с отображением трафика
- `background.js` — service worker, маршрутизация сообщений между контекстами
- `content/syringe.js` — контент-скрипт, внедряет сниффер в страницу (document_start)
- `lib/socket-sniffer.js` — перехватчик WebSocket (патчит `WebSocket` в контексте страницы)
- `pako.min.js` — распаковка сжатых сообщений (permessage-deflate)
- `manifest.json` — манифест расширения (MV3)
